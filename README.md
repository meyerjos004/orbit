# HELIOS

A 3D idle space game by King. Free to play and free to embed.

**Play:** https://meyerjos004.github.io/orbit/

Progress saves in your own browser (no account). On iPhone: open in Safari → Share → Add to Home Screen, and play from that icon.

## Embed it anywhere
```html
<iframe src="https://meyerjos004.github.io/orbit/" style="width:100%;height:100%;border:0" allow="fullscreen; autoplay" title="HELIOS"></iframe>
```
Saves are kept per site (each page that embeds it gets its own save).

Planet textures: Solar System Scope (CC BY 4.0). Rock/studio textures: Poly Haven (CC0).
